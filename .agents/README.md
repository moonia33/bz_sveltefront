# Agent workspace

This folder stores project-specific guidance for Copilot and other coding agents.

## Contents
- `.github/copilot-instructions.md` — repository-wide instructions for SvelteKit + Preline work
- `skills/` — domain-specific skill instructions for specialized workflows

## Recommended workflow
1. Use the repo-level instructions for general coding practices.
2. Use the skill files for specialized tasks such as Preline integration or theme generation.
3. Keep guidance specific, concise, and project-focused.

## Project profile
- Framework: SvelteKit
- Styling: Tailwind CSS
- UI library: Preline
- Goal: maintain a consistent design system, accessible components, and maintainable implementation patterns
